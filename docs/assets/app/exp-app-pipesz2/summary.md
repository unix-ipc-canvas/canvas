# 설계 비교: exp-app-pipesz2

`scripts/compare-app.py` 가 `results/exp-app-pipesz2/` 에서 만든 파일이다. 손으로 고치지 않는다.
폴더 18개(1m-free-1, 1m-free-2, 1m-free-3 ...)를 읽었다. 기준 설계는 `64k` 이다. 
처리량(응용은 msg/s)은 동시 요청이 1보다 큰 조건, 지연(p50, µs)은 동시 요청 1인 조건의 값이다. 메모리는 VmHWM(최대 RSS, KB)이고 클라이언트는 클라이언트별 값의 중앙값이다. 값은 같은 조건의 모든 실행의 중앙값이고 괄호는 실행 수다.
판정은 기준과 비교한 것이며, 실행별 값의 가운데 범위(좋은 쪽과 나쁜 쪽 4분의 1씩 뺀 것)가 겹치면 ≈ 다.
