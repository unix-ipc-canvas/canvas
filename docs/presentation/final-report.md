# 최종보고서·제출 준비 기준 — 공유 캔버스 서버

[문서 안내](../../README.md#관련-문서)

최종보고서의 각 절을 어떤 자료로 채우는지와 제출물 점검을 담당한다. 제출 요건의 원본은 [과제 핵심 정리](../assignment/README.md#제출물), 보고서 목차의 원본은 [최종보고서 서식](../assignment/UNIX시스템프로그래밍_설계과제_최종보고서서식.docx)이다. 발표자료와 동영상은 [최종 발표 준비 기준](final-presentation.md)을 따른다.

## 제출물 점검

| 제출물 | 만드는 방법 | 확인 |
| --- | --- | --- |
| 최종보고서 | 서식의 목차와 항목 순서 그대로. 아래 [보고서 절별 출처](#보고서-절별-출처)에서 옮긴다 | 안내 문구 삭제, 그래프의 축 이름과 단위, 수치마다 측정 조건 |
| `osproject_2.tar` | `make dist` | 풀어서 `make` 통과, `readme.txt` 빈칸 없음, `results/`에 원자료 있음 |
| 발표자료(PPT) | [발표자료 구성](final-presentation.md#발표자료-구성) | 쪽수 범위 |
| 발표 동영상 | PPT 진행 + 데모 화면 | 재생 확인. 용량이 크면 동영상만 이메일 제출 |

제출은 11월 30일(월), e-class 업로드 시각 기준이다.
