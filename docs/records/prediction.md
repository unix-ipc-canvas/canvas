# 워크로드 명세와 성능 예측 (보고서 3장 원본) — 공유 캔버스 서버

[문서 안내](../../README.md#관련-문서)

**규칙**
1. 이 문서는 2단계 응용 코드(server.c, client.c)를 쓰기 **전에** 작성하고 커밋합니다. 커밋 시각이 "구현 전 작성"의 증거입니다.
2. 커밋한 뒤에는 위쪽 내용을 고치지 않습니다. 생각이 바뀌면 맨 아래 "수정 기록"에 날짜, 바꾼 내용, 이유를 덧붙입니다.
3. 예측은 1단계에서 **우리가 잰 숫자**를 근거로 씁니다. "shared memory가 빠르다" 같은 일반론은 점수가 없습니다.
4. 가능하면 숫자로 예측합니다. 숫자가 있어야 나중에 "얼마나 틀렸는지"를 말할 수 있습니다.

상태: 미작성 (목표 11/16)

옵션의 뜻은 [실행 옵션](../tech-specs/02-design.md#실행-옵션), 측정값을 읽는 법은 [측정 방법](../tech-specs/03-measurement.md)을 따른다.
