## 2. AI가 틀린 것과 바로잡은 과정

- **시험 도구의 경쟁(CI 실패)**: 재수행 PR의 CI에서 T-22만 실패했다. 로컬에서 100번, CPU 부하를 걸고 100번 돌려도 재현되지 않아, AI가 만든 시험 스크립트가 서버 준비를 '시작' 줄로 판단하는 부분을 의심했고, 로그 파일을 비우는 리다이렉션만 0.2초 늦추는 조건으로 CI와 같은 실패를 재현했다(3번 표).
- **pipe 시작 구간 TOCTOU**: 위 원인을 찾는 동안 서버 둘을 같은 순간에 띄우는 실험을 CPU 부하만 바꿔 돌려, FIFO를 다시 만드는 사이의 경쟁을 찾았다(부하 12에서 150쌍 중 21쌍이 둘 다 뜸). 부하가 없을 때는 150쌍 모두 정상이라 기존 시험으로는 드러나지 않았다(3번 표).
- **개선 시험의 오류(T-26)**: 개선 모드 재접속 시험이 모두 실패했을 때 개선 코드를 의심하기 전에 시험 쪽을 확인해, 서버를 그림판 1개로 띄운 시험 오류임을 찾았다(3번 표).
- 측정 결과와 맞지 않았던 AI의 예측·설명은 2번 표와 [2단계 측정 결과](../../measurement/stage2.md)에 있다.
