## 2. AI가 틀렸던 사례 (최소 2개)

실제로 확인한 것만 적습니다. "확인 방법"에는 우리가 돌린 명령이나 측정 결과를 적습니다.

| 번호 | 날짜 | AI의 제안·설명 | 실제로 확인한 내용 | 확인 방법과 조치 |
| --- | --- | --- | --- | --- |
| 1 | | | | |
| 2 | | | | |

AI가 한 말 중 우리 컴퓨터에서 직접 확인해 볼 것 (틀렸으면 위 표로 옮기기)

- [ ] System V 메시지 최대 크기 8192B, 큐 용량 16384B → `cat /proc/sys/kernel/msgmax /proc/sys/kernel/msgmnb`
- [ ] 파이프 버퍼 기본 64KB, PIPE_BUF 4096B → `fcntl(fd, F_GETPIPE_SZ)`, `getconf PIPE_BUF /`
- [ ] "작은 메시지에서는 shared memory가 pipe보다 빠르지 않을 수 있다" → 1단계 64B 측정
- [ ] "mq로 1MB를 보내면 조각마다 송수신이 교대한다" → 1단계 1MB 측정의 자발적 컨텍스트 스위치 수
- [ ] AI가 설계 문서에 적은 그 밖의 숫자와 예상 전부

지금까지 확인된 것

- 11/12 이동건 PC(Ubuntu, 커널 7.0.0)에서 `msgmax` 8192, `msgmnb` 16384, `PIPE_BUF` 4096, `pipe-max-size` 1048576을 확인했다. AI의 설명과 같았다. 측정용 컴퓨터에서 다시 확인한다.
- 11/12 AI가 캔버스 저장 형식을 PPM이라고 적어 왔으나, 한 칸 1바이트 회색조는 PGM이 맞다. AI가 문서를 다시 쓰다가 스스로 고쳤다. 사례로 쓸지는 팀이 정한다.
